# 写作规范：怎样把力学讲严谨

本库不是散文集，也不是公式手册。每一页都按同一套"可核对"的结构写，
目的是让学生**能自己把推导重做一遍**，而不是记住结论。

---

## 1. 六节固定结构

```
## 0. 结论先行
## 1. 前提与符号
## 2. 推导
## 3. 数值检验
## 4. 常见误解
## 5. 自测
```

### 0. 结论先行
- 用 1–3 句话说清"这一页要证明什么"。
- 给出**适用范围**（例如"仅适用于连续介质、小变形"）。
- 给出**与前后文的接口**（依赖哪一页、被哪一页使用）。

### 1. 前提与符号
- 假设逐条列出，每条注明"如果不满足会怎样"。
- 新符号必须在第一次出现处定义，并回到 `symbols-and-conventions.md` 对齐。

### 2. 推导
- **编号步骤**：每一步只做一件事（一次平衡、一次投影、一次代数变形）。
- 每一步写**依据**：静力平衡？几何投影？张量变换律？特征值定义？
- 禁止"显然""易得""可以证明"跳步。若某结论超出本页范围，明确写"这一步用到 X（见某页/某定理）"。
- 代数推导保留中间式，至少到"读者能接上"的程度。

### 3. 数值检验
- 用**能心算或计算器验算**的数字，不用复杂参数。
- 检验要能**证伪**：算出的数与另一条独立路径的结果对上，才算通过。
- 经典数字：单轴 100 MPa、纯剪 50 MPa、静水 100 MPa。这三个数在多个页面复用，便于交叉核对。

### 4. 常见误解
- 格式固定为：**错的说法 → 为什么错 → 正确的说法**。
- 误解必须是真实的（来自学生提问或常见教材误读），不写稻草人。

### 5. 自测
- 3–5 题，难度递增；至少一题要求动手算，至少一题要求判断对错并说明理由。
- 答案放在文末 `<details>` 折叠块里，先自己想。

---

## 2. 公式与图

- 行内公式用 `$...$`，独立公式用 `$$...$$`。
- 符号首次出现时说明含义；不同页面同一符号含义必须一致。
- 图必须**有编号 + 图题 + 一句话结论**（"从图中可以看到……"），不能只放图。
- 图必须由 `tools/make_figures.py` 生成，并在图题里给出文件名，保证可复现。
- 不复制他人图像；需要引用原图时放到 `assets/reference/` 并注明 DOI 与许可。

---

## 3. 语言

- 中文正文，专业术语中英并列一次（例："主应力（principal stress）"）。
- 句子短，一句话只讲一件事。公式前后各留一行说明"为什么写这个式子"。
- 不用"众所周知""不言而喻"；学生不懂的正是"众所知"。

---

## 4. 引用与出处

- 引用文献用 DOI 或完整链接，写在页面末尾的"延伸阅读"。
- 吸收外部文章（公众号、教材、论文）时，在 `cases/` 建独立笔记，
  正文只引用其结论，不搬运其文字与图片。
