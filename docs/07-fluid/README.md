## 1. 这一模块解决什么

M6 讲的是"固体和多孔介质怎么离散"：单元、形函数、组装、约束、求解器。
M7 讲的是"流体怎么离散"：**状态量怎么存、面上通量怎么算、时间怎么推进**。
两者共用线性代数与收敛判据，但未知量的组织方式不同：

| 对比项 | M6 固体/多孔介质 | M7 流体 |
|---|---|---|
| 未知量 | 位移 $\mathbf u$、孔压 $p$ | 守恒量 $\mathbf U=(\rho,\rho\mathbf u,\mathcal E)$ |
| 方程性质 | 椭圆为主（平衡） | 双曲为主（对流），加抛物（扩散） |
| 离散 | 有限元，单元内积分 | 有限体积，面上通量 |
| 稳定性 | 网格、锁定、孔压奇异 | CFL、正性、低马赫刚性 |
| 边界 | 位移、荷载、孔压 | 按特征线计数 |
| 耦合处 | CEL、孔压 cohesive、Soils 步 | 同左：流体侧提供压力与通量 |

CEL 与孔压耦合单元正落在两模块的交界：M6 讲它们在 Abaqus 里怎么设，
M7 讲流体侧的压力与通量怎么算。

## 3. 石油系统接口

这张表说明每章对应石油工程里的哪类问题，避免"学完不知道用在哪"。

| 场景 | 用到的章节 | 说明 |
|---|---|---|
| 井筒瞬变、气侵、关井压力波 | 01、02、03 | 一维可压缩管流；声速决定波速与显式步长 |
| 地面集输管线、水击 | 02、03 | 亚声速出口、总压入口、特征线边界 |
| 水力裂缝内高速流动 | 01、03 | 缝内可压缩流体；与 M4 的 cohesive 缝宽、M6 的孔压单元耦合 |
| 超临界 CO2 注入 | 01、03 | 状态方程换成真实气体，守恒形式与通量框架不变 |
| 储层渗流 | 不在此模块 | Darcy 定律控制，属多孔介质流动，见 M5、M6 |
| 盐构造 CEL | 03 的交界 | 欧拉流体与拉格朗日固体耦合，界面通量由两侧状态共同决定 |

要点：**N–S 不是万能的**。油藏尺度的渗流由 Darcy 定律控制，
雷诺数与孔隙尺度都不满足 N–S 的连续介质描述；把 N–S 直接套到储层，
得到的是错误的数量级。真正需要 N–S 的是井筒、管线、裂缝内高速流与地面设备。

## 4. 学习目标

1. 写出可压缩 N–S 的守恒形式，说明每一项的物理意义与量纲。
2. 说清 5 个方程、7 个未知量、2 个状态关系之间的封闭关系。
3. 从状态量恢复原始量，并解释单元平均带来的非线性误差。
4. 按外法向数特征线，判断四类边界各需几个外部条件。
5. 构造亚声速出口的边界状态，并用数值通量施加。
6. 手算一个面的 Rusanov 通量与两个单元的更新。
7. 由声速与网格尺寸估计显式步长，判断声学与黏性哪个限制更严。
8. 用精确解、守恒审计与网格收敛三件事验证一个可压缩求解器。

## 6. 关键结论（先记住）

- 可压缩与不可压缩的分界是"密度是否由状态方程独立闭合"，不是"密度是否变化"。
- 5 个守恒方程解 7 个未知量，必须补 2 个状态关系；少一个就解不出来，多一个就过约束。
- 激波处微分形式失效，只有守恒律的积分形式（跳跃条件）有意义。
- 边界条件不是"给个值"，而是"数几条特征线进入计算域"。
- 面通量是有限体积的全部物理；数值扩散是一阶格式的固有代价，不是程序错误。
- 显式步长先看声学 $\Delta t\le C_{\mathrm{CFL}}h/(|\mathbf u|+c)$，再看黏性 $\Delta t\lesssim h^2/(2\nu)$，取小者。
- 低马赫数下密度基格式的刚性比约为 $1/\mathrm{Ma}$，这是压力基与预处理存在的理由。
- 任何"算完了"都不等于"算对了"：守恒审计与精确解比较，两样都要。
