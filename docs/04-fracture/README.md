## 学习目标

1. 说明理论强度与实际强度差 1–2 个数量级的原因（Griffith 缺陷）。
2. 区分三种断裂模式（I 张开、II 滑移、III 撕裂），并写出裂尖应力场的 $1/\sqrt{r}$ 奇异形式。
3. 掌握 $K$、$G$、$J$ 积分三个量的定义与换算，理解 $K_{Ic}$ 作为材料常数的含义。
4. 说明内聚力模型（cohesive zone）如何去掉裂尖奇异性，以及 $t$–$\delta$ 曲线、$G_c$ 的作用。
5. 用水力压裂把 M1–M4 串起来：起裂压力、闭合压力、缝宽与净压力。

## 关键结论（先记住）

- 裂尖应力 $\sigma_{ij}\propto K_I/\sqrt{2\pi r}$，$r\to0$ 时奇异。
- $G=K_I^2/E'$，平面应力 $E'=E$，平面应变 $E'=E/(1-\nu^2)$。
- 水力压裂起裂压力（无滤失、裸眼）：$p_b=3S_{h\min}-S_{H\max}+\sigma_t-p_p$（压正）。
- 裂缝垂直于 $S_{h\min}$ 扩展，缝宽 $\propto$ 净压力 × 缝长 / $G$。
