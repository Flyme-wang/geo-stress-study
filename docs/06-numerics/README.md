## 学习目标

1. 从虚功原理推出有限元弱形式，说明"刚度矩阵"从哪来。
2. 理解孔压耦合单元（如 C3D8P）的自由度与"土力学（Soils）分析步"为什么要用非对称求解器。
3. 掌握三类裂缝建模的适用边界：
   - **cohesive 单元**：预置潜在裂缝面，能算缝宽与滤失；
   - **XFEM**：裂缝可穿过单元内部，适合扩展路径未知；
   - **CEL**：大变形、流固耦合（如盐构造、压裂液流动）。
4. 诊断不收敛：时间增量塌缩、孔压自由度奇异、单元畸变、接触状态振荡。
5. 建立"先验证、再外推"的习惯：网格无关性、能量平衡、量纲检查。

## 关键结论（先记住）

- 孔压耦合问题中，孔压自由度在完全闭合/完全排干区域会退化 → 需要稳定化或调整边界。
- 时间增量突然塌缩，通常不是"数值噪声"，而是某个本构或接触状态发生了突变。
- 网格无关性检查：加密一级，关键量（缝长、面积、峰值压力）变化应 < 10%。
- 任何"算完了"都不等于"算对了"：必须核对注入体积、能量、边界反力。
