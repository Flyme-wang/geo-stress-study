# M1 应力状态

> 本模块回答一个问题：**怎样完整地描述一个点的受力状态，并从中读出方向信息？**

完成本模块后，学生应当能够：

- 说明"应力为什么依赖截面方向"，并用 Cauchy 公式算任意截面上的面力；
- 由应力张量求出主应力、主方向、不变量；
- 画出二维与三维莫尔圆，判断最大剪应力及其所在截面；
- 解释等效应力的来源与局限；
- 在拉正/压正两套约定之间正确换算。

## 建议讲授顺序（4 学时）

1. **第 1 学时**：01 + 02。用"同一根棒，不同方向切"建立直觉，然后严格化。
2. **第 2 学时**：03。把"主应力"从"另一股力"的误解里救出来。
3. **第 3 学时**：04。莫尔圆当作"变换公式的图形计算器"，强调角度翻倍。
4. **第 4 学时**：05 + 06。从"状态"走向"判据"和"地质应用"。

每个学时配 1 张图 + 1 个手算例题 + 2 道课堂即时题（见各页"自测"）。
